# Figures

Generated by `bench/make_figures.py` directly from the committed result CSVs, so they stay in
lockstep with the numbers rather than being redrawn by hand.

```bash
python3 bench/make_figures.py          # SVG (used by the markdown, dark-mode aware)
```

PNG copies are provided for contexts that do not render SVG reliably (Devpost uploads, PDF
export). To regenerate them:

```bash
docker run --rm -v "$PWD:/w" -w /w --entrypoint /bin/sh alpine:latest -c \
  'apk add --no-cache rsvg-convert font-dejavu >/dev/null 2>&1;
   for f in figures/*.svg; do rsvg-convert -w 900 "$f" -o "${f%.svg}.png"; done'
```

The palette is the validated categorical pair (blue `#2a78d6` / orange `#eb6834`), which clears
the colourblind-separation and contrast gates on both light and dark surfaces. Colours are
emitted as literal presentation attributes with dark mode applied as a CSS override, because CSS
custom properties are not resolved by every SVG rasteriser.
